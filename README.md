# Interactive Supplementary Material

## Jet-induced Mach stem bifurcation in three-dimensional in-phase cellular structure detonation

**Yaroslava Poroshyna, S. She-Ming Lau-Chapdelaine, Gabriel Ciccarelli**

Department of Mechanical and Materials Engineering, Queen's University, Kingston, Ontario, Canada

Submitted to the *Proceedings of the Combustion Institute*

---

### About this repository

This repository contains interactive 3D visualizations of the detonation front structure, provided as supplementary material for the paper listed above.

Each figure shows the shock surface and two iso-surfaces of the reaction zone progress variable *Y*r located behind the shock front, where *Y*r = 0 means reactions have not yet started and *Y*r = 1 means reactions are complete. The two iso-surfaces correspond to *Y*r = 0.1 and *Y*r = 0.95. The figures are rendered interactively using [Plotly](https://plotly.com/javascript/) and can be rotated, zoomed, and explored in the browser.

The simulations were performed in a square channel accommodating half a detonation cell across its width for a 2H₂+O₂+2Ar mixture, using a 3D Euler solver with adaptive mesh refinement and a tuned two-step reaction model.
